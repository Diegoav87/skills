# Labels

The engineering skills apply one label to the work they publish to the tracker.

| Label             | Meaning                                                                                  |
| ----------------- | ---------------------------------------------------------------------------------------- |
| `ready-for-agent` | The issue/ticket is fully specified and ready to be implemented. Applied by `/to-spec` and `/to-tickets`. |

`/implement` picks up `ready-for-agent` tickets from the frontier. Edit the label string above if your tracker uses a different one.
